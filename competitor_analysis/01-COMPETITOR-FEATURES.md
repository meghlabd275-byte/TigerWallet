## 1. Trust Wallet
**Sources:** trustwallet.com, trustwallet.com/swap, developer.trustwallet.com

- **Type:** Non-custodial / self-custody, multi-chain. iOS + Android + browser extension. No account. ~200M users. Owned by Binance-affiliate group.
- **Chains:** 100+ blockchains (BTC, ETH, Solana, Cosmos, Optimism, Polygon…), 10M+ assets, 600M+ supported NFTs.
- **Accounts / keys:** Self-custody (keys + secret phrase never leave device). Encrypted **Cloud Backup** for recovery.
- **Create/import:** create/import by seed; watch-only + hardware wallet historically supported (Ledger/Trezor/Keystone/GridPlus/WalletConnect) *(brands n.c.)*.
- **Interop:** built-in **dApp browser** (mobile), WalletConnect; extension injects EIP-1193 provider.
- **Swap/DEX:** **Native Swap**, 1M+ pairs, best-rate routing, slippage protection, multi-DEX routing, gas-efficient; **limit orders**; **Perpetuals up to 100× leverage (self-custody)**.
- **Staking/DeFi:** staking & earn across chains.
- **Buy/sell:** fiat buy/sell; deposit from exchanges.
- **NFT:** view/send/buy; 600M+ NFTs.
- **Tokens:** add custom tokens; **Security Scanner** validates token/contract before purchase.
- **Portfolio:** multi-asset analytics across 100+ chains.
- **Security:** seed encryption, Encrypted Cloud Backup, risky-address/dApp alerts, Security Scanner, zero tracking, independently audited, ISO certified.
- **Unique/differentiators:** one of the largest user bases; perps + limit orders; Encrypted Cloud Backup; developer Wallet-as-a-Service.

## 2. MetaMask
**Sources:** metamask.io, docs.metamask.io/wallet

- **Type:** Non-custodial. Browser extension + mobile. Dominant EVM wallet.
- **Chains:** Ethereum + **all EVM** networks, **and Solana** (multi-chain).
- **Accounts/keys:** BIP-39 12-word seed, local encrypted storage, self-custody.
- **Create/import/hardware:** create/import by seed; **hardware wallet** (Ledger/Trezor/Keystone/OneKey/Lattice…) *(brands n.c.)*.
- **Interop:** industry-standard injected provider (**EIP-1193 / EIP-6963**), WalletConnect, **MetaMask SDK** (QR/deeplink/multichain).
- **Swap/DEX:** **MetaMask Swaps** aggregator (best price, low gas); **Perps up to 50×**.
- **Staking/DeFi:** ETH staking; **RWAs (tokenized stocks/ETFs)**; **Prediction markets**.
- **Buy/sell:** fiat on-ramp (card/bank).
- **Card/money:** **MetaMask Card**; **Money hub** (save/spend/earn); **mUSD** (MetaMask USD stablecoin).
- **NFT:** NFT support via portfolio/dapp (no first-party marketplace *(n.c.)*).
- **Extensibility:** **MetaMask Snaps** — plugin system (custom chains, protocols, insights) — flagship differentiator.
- **Institutional/enterprise:** **Embedded Wallets** (MPC key management for devs), Smart Accounts Kit / Delegation Toolkit, Infura.
- **Unique:** Snaps, Embedded/MPC, Smart Accounts, perps, RWA trading, mUSD, prediction markets.
